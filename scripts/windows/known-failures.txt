# this file and fails on:
#   - a test that fails but is NOT listed here  -> regression
#   - a test listed here that passes or skips   -> stale entry, delete it
#   - a listed name matching no test at all     -> stale entry, delete it
#   - a test that starts but never finishes     -> incomplete run
#   - a package that fails with no failing test -> failure outside the tests

# the gate reads this file from the candidate checkout, so a change could add a
